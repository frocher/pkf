# Description

React covers the ability to build and maintain component-based user
interfaces with React — componentizing a design into reusable pieces,
managing state and data flow across them, and integrating with a
shared component library or design-token system rather than
hand-rolling one-off markup per screen. It is the skill the Customer
Portal Redesign project leans on most heavily: `DEC003` committed the
project to a shared, component-driven design system consumed by both
web and mobile, which only pays off if the engineers building the
portal's web app (`APP003`) are fluent in composing and reusing
components rather than writing bespoke UI per feature — the exact
practice that produced the inconsistency risk (`R004`) the design
system exists to fix.

`SR003` sets the bar at Advanced-level React skill, Critical
criticality, with a headcount need of two — the same criticality level
as the migration project's Kubernetes requirement, reflecting how load-
bearing this skill is for the portal's success. Priya Sharma (`COMP002`)
is recorded as holding it at Advanced level with four years of
experience, though not yet certified; she is currently assigned as a
Developer on the Platform Migration project rather than the portal,
which means the portal's React staffing need is not obviously covered
by anyone already on that project's team.
